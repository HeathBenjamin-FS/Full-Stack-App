# Pokemon Team Builder/Search Engine

### Here is how to pull this down and run it for yourself!

1. You need to clone this repo to your machine and run `npm install` to get all of the packages that I used during development.
2. You need to open 2 windows/terminals (make sure you cd into both client and server!) and enter `npm run dev` into both of those windows/terminals.
   - This should make it so that both your front end and back end are running simultaneously.
3. After loading the site, you will have the ability to create Pokemon and Trainers using the forms located at the top of the page.
4. After you start to get a good collection going, you will be able to assign Pokemon to Trainers, if you haven't already.

#### This is just about all you need to do in order to fully utilize this application!
